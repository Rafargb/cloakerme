# Cloakby Local (Full Reverse-Engineered Suite)

Cópia local completa da plataforma **Cloakby** (`app.cloakbyco.com`), reconstruída a partir dos bundles originais e pré-carregada com os dados da sua conta (`paulo@aimedialab.online`, plano **GLOBAL / ADMIN** desbloqueado).

## Como iniciar

No terminal:
```bash
cd /Users/apple/.gemini/antigravity/scratch/cloakby-local
npm run dev
```

Ou dê dois cliques no arquivo `start.command`.

Acesse no navegador:
- **Criativos (FFmpeg Engine)**: `http://localhost:3000/dashboard/creatives`
- **Camuflagem de Texto (Homóglifos + Zero-Width)**: `http://localhost:3000/dashboard/text-cloak`
- **Campanhas & UTMify Merger**: `http://localhost:3000/dashboard/campaigns`
- **Páginas (White / Black)**: `http://localhost:3000/dashboard/pages`
- **Logs de Cliques & Simulador de Tráfego**: `http://localhost:3000/dashboard/logs`
- **Visão Geral (Globo & Inteligência de Tráfego)**: `http://localhost:3000/dashboard`
